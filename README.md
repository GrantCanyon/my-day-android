# My Day — Мой день

Локальный Android-планировщик: расписание, список задач, заметки и JSON-резервные копии. Написан на Java с XML-разметкой и SQLite; интерфейс приложения — русский.

Это личное приложение, созданное с помощью ИИ для повседневного планирования. Владелец определял требования, проверял предыдущие сборки на телефоне и давал обратную связь; основную реализацию выполнили ИИ-помощники. Проект дополняет основное инженерное портфолио. Публичная версия содержит только синтетическое демонстрационное расписание.

**Статус: предварительная версия 0.2.** Подготовленная публичная сборка успешно собиралась, но ещё не прошла свежую проверку всех сценариев на устройстве. Это не подтверждённый стабильный релиз. Успешная сборка и проверки предыдущих версий на телефоне не заменяют проверку текущего приложения.

## Возможности

- Расписание дня по времени и отдельный компактный список дел; фильтр незавершённых задач.
- Создание и редактирование дел, времени и заметок; отметки выполнения 0%, 50% и 100%.
- Изменение порядка задач перетаскиванием и перенос на другую дату. Перенесённая задача добавляется в конец выбранного дня.
- Локальное хранение в SQLite с транзакционными изменениями.
- Экспорт читаемого Markdown-плана и JSON-резервной копии; импорт JSON с объединением задач по идентификатору.
- Необязательные локальные напоминания для задач с указанным временем.
- Небольшая демонстрационная неделя, даты которой привязываются к первому запуску.

Аккаунта и сервера нет; разрешение на доступ в Интернет не запрашивается. Демонстрационные задачи не воспроизводят личное расписание владельца.

## Сборка

| Компонент | Версия |
| --- | --- |
| JDK для сборки | 21 |
| Уровень исходного Java-кода и байткода | 17 |
| Gradle Wrapper | 8.13 |
| Android Gradle Plugin | 8.13.2 |
| Compile SDK | 37 |
| Target SDK | 36 |
| Минимальная версия Android | 8.0 / API 26 |
| Build Tools | 36.0.0 |

Откройте папку проекта в Android Studio и выберите JDK 21 для Gradle. Установите компоненты SDK:

```sh
sdkmanager "platforms;android-37.0" "build-tools;36.0.0" "platform-tools"
```

Укажите путь к SDK в переменной `ANDROID_HOME` или в локальном файле `local.properties`: `sdk.dir=/path/to/Android/Sdk`. Выполните из корня репозитория:

```sh
# Linux / macOS
bash ./gradlew --no-daemon assembleDebug
```

```powershell
# Windows PowerShell
.\gradlew.bat --no-daemon assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Gradle создаёт локальный отладочный ключ; приватные ключи в репозиторий не включены. Отладочная сборка предназначена для локальной проверки.

## Проверки и их границы

В [GitHub Actions](.github/workflows/android.yml) настроена сборка debug APK. Само наличие workflow не подтверждает успешный удалённый запуск. Эмулятор, Android instrumentation и проверка доставки уведомлений в этом workflow не запускаются.

В debug-сборке есть отдельная команда самопроверки операций с данными. После установки на тестовое устройство или эмулятор её можно выполнить вручную:

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am instrument -w -r ru.grant.planner/ru.grant.planner.PlannerDataSelfTest
```

Самопроверка проверяет изолированные операции с данными, а не весь интерфейс. **Её выполнение на текущей публичной сборке пока не подтверждено:** наличие команды не считается результатом её запуска.

Предыдущие частные сборки проверялись на телефоне; замечания использовались при доработке. Для текущей публичной версии приёмочная проверка на устройстве ещё не завершена. Обязанности компонентов и оставшиеся ручные проверки описаны в [заметках о разработке](docs/DEVELOPMENT.md).

## Ограничения

- Для напоминаний используются неточные Android-будильники. На Android 13+ нужно разрешение на уведомления; ограничения батареи могут задерживать доставку. Приложение не предназначено для сигналов, где критична точная секунда срабатывания.
- Часовой пояс расписания по умолчанию — `Europe/Moscow`; в JSON-резервных копиях сохраняется значение часового пояса.
- Для восстановления и редактирования поддерживается JSON. Markdown — экспорт для чтения; импорт расписания из PDF не реализован.
- Данные остаются на устройстве, пока пользователь их не экспортирует. Перед очисткой данных или удалением приложения сохраните JSON-резервную копию.
- Нет облачной синхронизации, механизма повторяющихся задач и совместной работы.
